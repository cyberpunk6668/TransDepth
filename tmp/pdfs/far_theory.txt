3. 从 GT 深度构造 FAR 教师：逐步求解
3.1 先解决⼀个 patch 代表什么表⾯
⼀个 16× 16 patch 可能同时覆盖玻璃、桌⾯和孔洞。两种表⾯深度的平均值可能对应⼀个根本不存在的中间
表⾯。因此教师先选可靠 patch，再计算深度关系。
设⼀个 patch 中⾮ padding 的候选像素集合为 V_i，其中正、有限、位于预定标签范围的像素集合为
V_i^valid。有效覆盖率是 |V_i^valid|/|V_i|；类别纯度是在固定标签有效规则下同类别像素的⽐例。原计划使
⽤⾄少 90% 的有效覆盖和类别纯度，并以 IQR(log(Z/(1m)))≤0.1 作为初始深度⼀致性阈值；IQR 指第 75 百
分位减第 25 百分位。除以 1m 表⽰先把深度变为⽆量纲⽶制数值；换⼀个固定参考单位只会给所有 log 深度
加同⼀常数，不改变 IQR。阈值是待开发集确认的设计参数，具体边界与百分位算法要在实现时固定。
把通过筛选的透明 queries 记为 T，通过筛选的⾮透明 queries 记为 B，其他混合或⽆效 queries 记为 U 。把
能够提供可靠深度代表值的图像 keys 记为 K _rel，它可以包含透明或背景 patches，但排除前缀、padding、
⽆效和混合边界。
对可靠 patch i，令 z_i^*>0 为合法像素深度的中位数。这⾥星号表⽰ G T。中位数⽤于降低少数异常值的影
响；它仍是 patch 级代表值，不是 patch 内每⼀个像素的真实深度。
边界仅退出关系监督，其合法像素仍进⼊深度损失。G T mask 不传⼊ DINOv3 的 patch masks 参数。

5.3 为什么两个好头相加不⼀定更好〔D2〕
设单头 h ₁ 、h ₂  的平均收益分别为 Δ_{h ₁ }、Δ_{h ₂ }，同时⼲预的收益为 Δ_{h ₁ ,h ₂ }。定义交互项
从“总收益=单头收益之和＋额外相互作⽤”移项即得该式。⽹络中的⾮线性、两个头内容重叠以及下游敏感
性，都可能使交互项为负。即便 attention ⼦层中两头的特征增量可相加，M AE 的变化也不线性可加。因此默
认只适配⼀个 head；两个 heads 必须重新检验联合效果。
5.4 oracle 能说明的范围
Oracle 为每张图读取 G T 来构造 P，属于特权诊断；它不是 RG B-only 部署结果。它也不是学⽣性能的严格上
界：学⽣会训练 Q/K  和读出，⽽ oracle 的读出固定。
完整证据链有四个不同问题：
1. ⼲预关系是否有⽤？
2. 单 RG B 学⽣能否学会其中可预测的部分？
3. 是否超过同容量、同训练预算的普通 LoRA？
4. 是否在封存真实域成⽴？
任何⼀项都不能直接推出后⼀项。

9.4 实际 RoPE 为什么破坏这个简单秩结论
RoPE 对不同 token 使⽤不同 R_i，这不是整个矩阵右乘同⼀个 R。
最⼩例⼦：两⾏原本都是 (1,0)，矩阵秩为 1；第⼀⾏旋转 0°，第⼆⾏旋转 90°，得到两条正交⾏，秩变成 2。
每⾏旋转都保⻓度，但不保整个跨 token 矩阵的秩。
所以 rank(δQ)≤r 不保证 rank(δ Q  )≤r，实际 H/16+ 不能直接套⽤ rank(ΔS)≤2r。
安全的⼀般界来⾃：学⽣ S^s= Q  ^s( K  ^s)^ ⊤ /√d 的秩不超过 d，原始 S^0 同样不超过 d。因此
新增数值检查给出 rank-1 投影增量经过逐 token 旋转后，打分增量秩达到 4、严格⼤于 2r=2 的反例。这不是
说实际训练⼀定达到该秩，⽽是反驳“所有情况下必定≤2r”的断⾔。
softmax 还是⾮线性变换，A^s−A^0 也不能被称为低秩概率更新。本⽂只对权重增量 ΔW=ηU B 声明低秩。

13.6 为什么评价协议属于理论可信度的⼀部分
主表在 384× 512 内容坐标去 padding 后⼀致评估；历史 144× 256 协议另表。透明、背景和预定边界带分别

主表明确遵从原计划：先逐图计算该区域指标，再在场景内对合法图像平均，最后对合法场景等权宏平均。令
m_I 表⽰⼀张图像的某个区域指标，G _eﬀ 表⽰该指标有合法图像的场景集合，I_g 表⽰场景 g 内合法图像集
合，则
内层分⺟给场景内图像等权，外层分⺟给场景等权；某场景没有该区域有效图像时，不虚构⼀个零误差。补充
表则可将所有有效像素的绝对误差相加，除以总像素数，得到 pooled M AE；pooled RM SE 将绝对误差改成平
⽅误差，在总体平均后开根。
对于不同图像，逐图 RM SE 的平均不等于 pooled RM SE，因为平⽅根是⾮线性的。例如两张图像等⼤、每图
均⽅误差分别为 0 和 4，平均逐图 RM SE=(0+2)/2=1，⽽ pooled RM SE=√((0+4)/2)=√2。按场景宏平均也不
等于按全部像素池化：前者给场景相同权重，后者给⼤区域更多权重。
测试不能⽤ G T 拟合尺度、平移、median ratio 或仿射。若预测含 NaN∕Inf，要按预定规则报告失败和惩
罚，不能删除困难像素后计算更低误差。
配对 bootstrap 应重抽真正独⽴的组。设共有 G  个独⽴组、每组误差差值为 d_g，每次均匀有放回抽 G  个组
索引，再平均抽中的 d_g，形成重抽分布；取其第 5 百分位得到计划所⽤的近似单侧 95% 下界。把百万个相
关像素当成独⽴样本会夸⼤证据。
多种⼦⽅差反映优化随机性，组 bootstrap 反映评估组变化，两者不可混成⼤量独⽴样本。跨种⼦平均误差也
不等于先平均预测再评估的 ensemble。
